Prompt Studio — เครื่องมือสร้าง JSON สำหรับแก้ไขภาพ AI

วางแผนการแก้ไขเป็นจุด ๆ สร้างคำสั่งแบบมีโครงสร้าง และบันทึก Prompt ไว้ใช้ซ้ำ

1. ภาพและโปรเจกต์

ภาพจะถูกใช้เป็นภาพอ้างอิงในขั้นตอนเขียน Prompt เท่านั้น ไฟล์ไม่ได้ถูกส่งออกไปกับ JSON

2. เพิ่มรายการแก้ไข (เลือกหัวข้อหลักและหัวข้อย่อย)

3. กฎการคงรายละเอียดและข้อห้าม

4. ผลลัพธ์ Prompt JSON

JSON นี้เป็นโครงสร้างกลาง พร้อมคำสั่งภาษาธรรมชาติสำหรับนำไปวางใน ChatGPT หรือ Google Flow

5. Prompt ที่บันทึกไว้

เก็บใน Local Storage ของเบราว์เซอร์เครื่องนี้ ไม่อัปโหลดขึ้นเซิร์ฟเวอร์

แนวทางใช้งานให้แม่นยำ

  • เพิ่มรายการแยกกันตามบริเวณ เช่น ใบหน้า เสื้อผ้า และฉากหลัง
  • ระบุพิกัดเป็นเปอร์เซ็นต์ 0–100 จากมุมซ้ายบน และแนบ Mask เมื่อเครื่องมือรองรับ
  • อัปโหลดภาพต้นฉบับในหน้าสนทนาของ AI ด้วย เพราะ JSON ไม่ได้ฝังไฟล์ภาพ
  • AI อาจไม่ตีความพิกัดเหมือนกันทุกระบบ ควรตรวจภาพผลลัพธ์และปรับทีละรอบ
