ผมสร้างโปรแกรมเสร็จแล้วในไฟล์ **promptspell-atelier.html** เปิดด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ใช้ HTML, CSS และ JavaScript ไฟล์เดียว ผมตรวจแค่ว่าโค้ด JavaScript ไม่มี syntax error ยังไม่ได้เปิดทดสอบหน้าจอจริง

**ชื่อโปรแกรม:** PromptSpell Atelier (ห้องเสกพรอมต์) เป็นชื่อที่ผมตั้งขึ้นเอง ยังไม่ได้ค้นว่ามีคนใช้ซ้ำหรือไม่ ควรลองค้นใน Google ก่อนใช้งานจริง

**สิ่งที่โปรแกรมทำได้**
1. **ช่องชื่อภาพ** พิมพ์ได้ทั้งไทยและอังกฤษ ผลลัพธ์อัปเดตทันทีที่พิมพ์
2. **Dropdown 12 หมวด** ได้แก่
   - ประเภทภาพ, สไตล์ภาพ, ขนาดช็อต, มุมกล้อง
   - เลนส์, แสง, โทนสี, อารมณ์
   - ฉาก/พื้นหลัง, ช่วงเวลา/สภาพอากาศ, การจัดองค์ประกอบ, คุณภาพ
   - อัตราส่วนภาพ 8 แบบ (1:1, 16:9, 9:16 ฯลฯ)
   - ช่อง "รายละเอียดเพิ่มเติม" และ "สิ่งที่ไม่ต้องการ (Negative)"
3. **ปุ่ม ✦ Generate Auto** เดาหมวดจากคำในชื่อภาพ เช่น "แมว", "อาหาร", "วิว" แล้วเติมช่องที่ยังว่างให้เหมาะกับหมวดนั้น พร้อมเพิ่มคำบอกคุณภาพและ Negative prompt
4. **สลับภาษาไทย/English** เปลี่ยนทั้งเมนูและตัว Prompt ที่ได้
5. **ส่วนที่ผมเพิ่มให้**
   - เลือกแพลตฟอร์มได้ ChatGPT จะได้ Prompt เป็นประโยคแยกหัวข้อ ส่วน Google Flow จะได้เป็นคำคั่นด้วยจุลภาค พร้อมช่อง Negative แยก
   - ปุ่มสุ่มทั้งหมด และปุ่มล้างค่า
   - ปุ่มคัดลอก และตัวนับตัวอักษร
   - กล่อง Prompt แก้ไขต่อได้
   - ประวัติ 10 รายการล่าสุด กดเพื่อเรียกกลับมาใช้ (เก็บในเครื่อง)
   - รองรับโหมดมืดตามการตั้งค่าเครื่อง และใช้บนมือถือได้

**วิธีแก้ชื่อโปรแกรม** (ไฟล์ promptspell-atelier.html) ต้องแก้ 3 จุด

| บรรทัด | ตำแหน่ง | หน้าที่ |
|---|---|---|
| 6 | `<title>PromptSpell Atelier - ห้องเสกพรอมต์ภาพ AI</title>` | ชื่อบนแท็บเบราว์เซอร์ |
| 46 | `<h1 id="appName">PromptSpell Atelier</h1>` | ชื่อเริ่มต้นก่อนสคริปต์ทำงาน |
| 97 | `const APP_NAME = "PromptSpell Atelier";` | ชื่อหลักที่แสดงบนหัวโปรแกรม |

บรรทัด 97 คือจุดที่ต้องแก้แน่นอน เพราะสคริปต์จะเขียนทับชื่อบรรทัด 46 ทุกครั้งที่เปิดหน้า ส่วนบรรทัด 6 และ 46 แก้ให้ตรงกันเพื่อความเรียบร้อย
