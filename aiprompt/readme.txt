--------------- Prompt -------------------
สร้างโปรแกรมช่วยเขียน Prompt สำหรับ Generate รูปภาพด้วย ai (ChatGPT และ Google Flow) ด้วยภาษา HTML ร่วมกับภาษาอื่นที่เหมาะสม
ต่อไปนี้คือรายละเอียดที่ต้องการ 
1. มีช่องพิมพ์ชื่อภาพที่ต้องการ สามารถพิมพ์ข้อความได้ทั้งภาษาไทย และภาษาอังกฤษ
2. มีตัวเลือกเป็น Dropdown List ที่จำเป็นให้ครบถ้วน เช่น มุมกล้อง, โทนสี, อัตราส่วนของภาพ, นอกเหนือจากตัวอย่างแล้วอะไรที่ควรมีสร้างเพิ่มให้ด้วย
3. มีปุ่มสำหรับ Generate Auto เพื่อให้ได้ Prompt ที่มีรายละเอียดมากขึ้น
4. มีปุ่มสำหรับเปลี่ยนเมนู และข้อมูล Prompt เป็นภาษาไทย และภาษาอังกฤษ
5. สามารถสร้างส่วนเพิ่มเติมในส่วนที่คุณคิดว่าเหมาะสม และควรมี
6. ตั้งชื่อโปรแกรมไม่ให้ซ้ำใคร เขียนข้อแนะนำให้ด้วยว่าหากต้องการแก้ไขชื่อต้องแก้ที่บรรทัดไหน (ข้อแนะนำไม่ต้องใส่ในโปรแกรม) เขียนแนะนำไว้ด้านนอก
---------------------------------------------

ผมสร้างโปรแกรมเสร็จแล้วในไฟล์ **promptspell-atelier.html** เปิดด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ใช้ HTML, CSS และ JavaScript ไฟล์เดียว ผมตรวจแค่ว่าโค้ด JavaScript ไม่มี syntax error ยังไม่ได้เปิดทดสอบหน้าจอจริง

**ชื่อโปรแกรม:** PromptSpell Atelier (ห้องเสกพรอมต์) เป็นชื่อที่ผมตั้งขึ้นเอง ยังไม่ได้ค้นว่ามีคนใช้ซ้ำหรือไม่ ควรลองค้นใน Google ก่อนใช้งานจริง

**สิ่งที่โปรแกรมทำได้**
1. **ช่องชื่อภาพ** พิมพ์ได้ทั้งไทยและอังกฤษ ผลลัพธ์อัปเดตทันทีที่พิมพ์
2. **Dropdown 12 หมวด** ได้แก่
   - ประเภทภาพ, สไตล์ภาพ, ขนาดช็อต, มุมกล้อง
   - เลนส์, แสง, โทนสี, อารมณ์
   - ฉาก/พื้นหลัง, ช่วงเวลา/สภาพอากาศ, การจัดองค์ประกอบ, คุณภาพ
   - อัตราส่วนภาพ 8 แบบ (1:1, 16:9, 9:16 ฯลฯ)
   - ช่อง "รายละเอียดเพิ่มเติม" และ "สิ่งที่ไม่ต้องการ (Negative)"
3. **ปุ่ม ✦ Generate Auto** เดาหมวดจากคำในชื่อภาพ เช่น "แมว", "อาหาร", "วิว" แล้วเติมช่องที่ยังว่างให้เหมาะกับหมวดนั้น พร้อมเพิ่มคำบอกคุณภาพและ Negative prompt
4. **สลับภาษาไทย/English** เปลี่ยนทั้งเมนูและตัว Prompt ที่ได้
5. **ส่วนที่ผมเพิ่มให้**
   - เลือกแพลตฟอร์มได้ ChatGPT จะได้ Prompt เป็นประโยคแยกหัวข้อ ส่วน Google Flow จะได้เป็นคำคั่นด้วยจุลภาค พร้อมช่อง Negative แยก
   - ปุ่มสุ่มทั้งหมด และปุ่มล้างค่า
   - ปุ่มคัดลอก และตัวนับตัวอักษร
   - กล่อง Prompt แก้ไขต่อได้
   - ประวัติ 10 รายการล่าสุด กดเพื่อเรียกกลับมาใช้ (เก็บในเครื่อง)
   - รองรับโหมดมืดตามการตั้งค่าเครื่อง และใช้บนมือถือได้

**วิธีแก้ชื่อโปรแกรม** (ไฟล์ promptspell-atelier.html) ต้องแก้ 3 จุด

| บรรทัด | ตำแหน่ง | หน้าที่ |

| 46 | `<h1 id="appName">PromptSpell Atelier</h1>` | ชื่อเริ่มต้นก่อนสคริปต์ทำงาน |

บรรทัด 97 คือจุดที่ต้องแก้แน่นอน เพราะสคริปต์จะเขียนทับชื่อบรรทัด 46 ทุกครั้งที่เปิดหน้า ส่วนบรรทัด 6 และ 46 แก้ให้ตรงกันเพื่อความเรียบร้อย

JSON แก้ไขภาพ AI ให้เป๊ะทุกจุด (Detailed Image Manipulation)

สร้างโปรแกรมช่วยเขียน Prompt สำหรับ สร้าง JSON แก้ไขภาพ AI ให้เป๊ะทุกจุด (Detailed Image Manipulation) สำหรับ (ChatGPT และ Google Flow) ด้วยภาษา HTML ร่วมกับภาษาอื่นที่เหมาะสม
ต่อไปนี้คือรายละเอียดที่ต้องการ 
1. มีช่องพิมพ์ชื่อภาพที่ต้องการ หรือ แก้ภาพที่ทำการอัพโหลด สามารถพิมพ์ข้อความได้ทั้งภาษาไทย และภาษาอังกฤษ
2. มีตัวเลือกเป็น Dropdown List ที่จำเป็นให้ครบถ้วน หัวข้อ หลัก และ ย่อย เช่น 
	2.1 การควบคุมองค์ประกอบหลัก (Global & Subject Manipulation)
	 - เพิ่ม/ลด หรือแทนที่วัตถุหลัก (Object Insertion/Removal/Replacement): ระบุตำแหน่ง (Coordinates / Bounding Box) และชื่อวัตถุที่ต้องการเพิ่ม ลบ หรือเปลี่ยน เช่น เปลี่ยนจากเสื้อยืดสีดำเป็นแจ็คเก็ตหนัง
	 - ปรับเปลี่ยนท่าทางและอิริยาบถ (Pose & Gesture Modification): กำหนดท่าทางของตัวละคร เช่น จากยืนกอดอกเป็นชูสองนิ้ว หรือเปลี่ยนมุมองศาของศีรษะและลำตัว
	- การแสดงออกทางสีหน้า (Facial Expression): ควบคุมสีหน้า อารมณ์ แววตา รอยยิ้ม หรือการมองกล้อง/มองข้าง
	2.2 การควบคุมรายละเอียดเฉพาะจุดด้วย Inpainting / Masking 
	- ระบุพิกัดพื้นที่เฉพาะ (Mask Region Targeting): กำหนดพื้นที่ด้วยพิกัด $(x, y, w, h)$ หรือ Mask Channel เพื่อแก้ไขเฉพาะจุดที่ต้องการ โดยไม่ให้ส่วนอื่นของภาพเพี้ยน
	- ปรับแต่งเสื้อผ้าและเครื่องแต่งกาย (Clothing & Wardrobe Adjustments): เปลี่ยนสี ลวดลาย เนื้อผ้า (เช่น ผ้าไหม ผ้าฝ้าย) หรือดีไซน์ของเครื่องแต่งกายเฉพาะชิ้น
	- การแต่งหน้าและทรงผม (Hair & Makeup Tuning): เปลี่ยนทรงผม ความยาว สีผม หรือเพิ่มระดับการแต่งหน้า (เช่น ริมฝีปาก, อายไลเนอร์)
	2.3 การควบคุมแสง สี และบรรยากาศ (Lighting & Color Grading)
	- ทิศทางและคุณภาพของแสง (Lighting & Shadows): กำหนดแหล่งกำเนิดแสง (เช่น Backlight, Studio Softbox, Golden Hour) และทิศทางเงาตกกระทบ
	- การปรับแต่งสีเฉพาะจุดหรือภาพรวม (Color Palette & Grading): กำหนดค่าสี (Hex/RGB) หรือโทนสีของวัตถุแต่ละชิ้น รวมถึงเกรดสีของภาพรวม (เช่น Cyberpunk Neon, Cinematic Teal and Orange)
	- บรรยากาศและสภาพแวดล้อม (Atmosphere & Weather): ใส่หมอก ฝน แสงสะท้อน ละอองแดด (Volumetric Lighting) ลงไปในฉากหลัง
	2.4 การจัดการพื้นหลังและองค์ประกอบรอบข้าง (Background & Environment)
	- การเปลี่ยนฉากหลัง (Background Replacement): สลับฉากหลังเดิมออกแล้วใส่ฉากใหม่เข้าไป (เช่น จากห้องนอนเป็นคาเฟ่มินิมอล) โดยรักษาตัวละครหลักไว้คงเดิม
	- ระยะชัดลึกและสไตล์เลนส์ (Depth of Field & Camera Settings): ควบคุมค่ารูรับแสง (เช่น หน้าชัดหลังเบลอ / Bokeh), ทางยาวโฟกัสของเลนส์ (เช่น เลนส์พอร์ตเทรต 85mm หรือมุมกว้าง)
หมายเหตุ สำคัญ ข้อ 2 คือ:	นอกเหนือจากตัวอย่างแล้วอะไรที่ควรมีสร้างเพิ่มให้ด้วย,และหัวข้อหลักและ ย่อย ยาวเกิน Dropdown List ให้ย่อ แต่คงความหมาย และมีการ แสดงอธิบาย กรอบด้านล่างหรือ ด้านข้างได้ ว่า ข้อนี้คืออะไร ยาว ๆ ให้เข้าใจ หากเลือกแล้ว แต่ละข้อมี การต้องใส่ค่า คิดวิธีว่า จะทำยังไงให้ผมกรอกได้ถูก อาจเอา เทมเพส ของ ข้อนั้น ว่าง หรืออธิบายในการกรอก
3. มีปุ่มสำหรับ Generate Auto เพื่อให้ได้ Prompt ที่มีรายละเอียดมากขึ้น และให้เป็นแบบ json เพื่อ ให้ ai แก้ตาม ต้องการ
4. มีปุ่มสำหรับเปลี่ยนเมนู และข้อมูล Prompt เป็นภาษาไทย และภาษาอังกฤษ
5. สามารถสร้างส่วนเพิ่มเติมในส่วนที่คุณคิดว่าเหมาะสม และควรมี
6. สามารถ บันทึก prompt ที่ชอบไว้ แก้ไข หรือใช้ภายหลังได้

4. มีปุ่มสำหรับ Generate Auto เพื่อให้ได้ Prompt ที่มีรายละเอียดมากขึ้น
