1. ภาพต้นแบบและข้อมูลสติกเกอร์

ภาพจะแสดงตัวอย่างในหน้านี้ แต่ไม่ได้ถูกส่งไปยัง AI อัตโนมัติ ต้องแนบภาพเดียวกันตอนนำ Prompt ไปใช้
ใส่ข้อความเพื่อช่วยให้ AI ออกแบบท่าทางและเอฟเฟกต์ให้ตรงความหมาย หากไม่ทราบให้เว้นว่างและสั่ง AI อ่านจากภาพ

2. รูปแบบภาพและเฟรม

3. กำหนดแนวทาง Animation

4. กฎการคงรูปต้นฉบับ

หมายเหตุ: โปรแกรมนี้สร้าง JSON จากตัวเลือกแบบเรียลไทม์ ไม่ได้เรียก AI หรือทำ OCR เอง การวิเคราะห์ความหมายภาพ/ข้อความจะเกิดขึ้นเมื่อคุณนำ JSON ไปใช้กับโมเดล AI พร้อมแนบภาพต้นแบบ
